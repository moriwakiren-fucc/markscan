# MarkScan

紙のマークシートを**撮影 → 自動解析 → 確認・修正 → 採点**まで、ブラウザだけで完結させる採点システムです。サーバーもインストールも不要で、HTML / CSS / JavaScript のみで動作します。

🔗 **公開URL**: `https://<ユーザー名>.github.io/markscan/`

---

## できること

1. **テンプレート作成**
   問題数・選択肢数・ラベル形式（1,2,3… / A,B,C… / ア,イ,ウ…）を自由に指定し、四隅に位置合わせマーカー付きのマークシート用紙を生成します。印刷してそのまま解答用紙として使えます。

2. **模範解答の登録**
   次の3通りの方法で登録できます。
   - 模範解答用紙を撮影 / アップロードして自動解析
   - CSV または JSON ファイルを読み込み
   - 画面フォームで手入力

   自動解析した内容も、あとから自由に編集できます。

3. **生徒の解答登録**
   生徒ごとに解答用紙を撮影 / アップロード → 自動解析 → フォームに反映 → 確認・修正 → 登録、という流れを繰り返し、複数人分をまとめて管理します。

4. **採点結果の確認**
   模範解答と照合して自動採点。得点一覧、平均点、満点者数、設問ごとの正誤詳細を表示し、CSVとして書き出せます。

## 使い方（GitHub Pagesでの公開）

1. このリポジトリを GitHub にプッシュする
2. リポジトリの **Settings → Pages** を開く
3. **Source** を「Deploy from a branch」、**Branch** を `main`（`/root`）に設定して保存
4. 数分後、`https://<ユーザー名>.github.io/markscan/` でアクセスできるようになります

ローカルで試す場合は `index.html` をブラウザで直接開くだけで動作します（ビルドや依存パッケージのインストールは不要です）。

## 画像解析の仕組みと注意点

このシステムは外部のAI画像認識サービスを使わず、ブラウザの Canvas API だけで完結する仕組みです。

- 用紙の四隅にある黒いマーカーを検出し、撮影時の傾き・歪みを補正（透視変換）します
- 補正後の座標を使って各マーク欄の濃淡（塗りつぶし具合）を判定します

精度を保つために、撮影時は以下を心がけてください。

- できるだけ明るい場所で、真上から撮影する
- 四隅の黒いマーカーが必ず画像内に写り込むようにする
- 極端な斜め撮影や、強い影・反射がある状態は避ける

解析結果は必ず確認用フォームに反映されるため、誤認識があった場合はその場で修正してから確定できます。認識が怪しい設問（未マーク・複数マークなど）は自動でハイライト表示されます。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面全体のレイアウトとスタイル |
| `template.js` | マークシートのテンプレート生成（座標計算・描画） |
| `vision.js` | 画像解析エンジン（マーカー検出・傾き補正・マーク判定） |
| `answerkey.js` | 模範解答の登録画面のロジック |
| `students.js` | 生徒の解答登録画面のロジック |
| `results.js` | 採点結果の集計・表示・CSV出力 |
| `app.js` | 全体の状態管理・画面遷移・共通UI部品 |

---

## 動作環境

最近のモダンブラウザ（Chrome / Safari / Edge / Firefoxなど）で動作します。カメラ撮影機能を使う場合は、スマートフォンやカメラ付きPCのブラウザからのアクセスを推奨します。
